# PADANG SENTIMENT ANALYSIS 2026

Analisis sentimen percakapan publik tentang pembangunan Kota Padang.

- Periode awal: 5 September–5 November 2026
- Platform: TikTok, Instagram, Facebook, YouTube, X
- Kelas: positif, negatif, netral, campuran
- Model: Random Forest, Linear SVM, Multinomial Naive Bayes
- Fitur: TF-IDF unigram dan bigram

## Struktur

```
PADANG-SENTIMENT-ANALYSIS-2026/
├── data/padang_social_media_template.csv
├── notebooks/PADANG_SENTIMENT_ANALYSIS_2026.ipynb
├── outputs/
├── ANNOTATION_GUIDE.md
├── requirements.txt
└── README.md
```

## Cara menjalankan

1. Buka notebook di Google Colab.
2. Unduh template CSV, isi dengan data publik yang dikumpulkan melalui API resmi/akses yang diizinkan atau pencatatan manual.
3. Beri label sentimen secara manual.
4. Unggah CSV saat diminta notebook dan jalankan sel dari atas ke bawah.
